# Соглашения проекта

Сервис учёта семейных расходов: Telegram-бот с ИИ-агентом и веб-панель. Решения и их причины описаны в `docs/architecture.md`; перед изменением архитектуры сверяйся с ним и обновляй его.

## Правила, которые нельзя нарушать

- Бот работает с тратами только через `service.UserExpenses` (`svc.ForUser(id)`). Владельца задаёт сервер из `message.from.id`. Не добавляй `user_id` в схемы инструментов агента и не передавай в агент `*service.Service` для операций над тратами.
- Суммы внутри Go хранятся в копейках (`int64`). В JSON и в инструментах это рубли. Перевод только через `domain.ParseAmount` и `domain.FormatAmount`, никаких `float64` для денег.
- Валидация живёт в `service`, а не в хендлерах и не в агенте. Ошибки для пользователя возвращай как `domain.Invalid(...)`.
- Новые зависимости добавляй только при реальной необходимости. Клиенты Telegram и LLM намеренно написаны на `net/http`.

## Как проверять изменения

```bash
cd backend && gofmt -l . && go vet ./... && go test ./...
cd frontend && npm run build
docker compose up -d --build
```

Изменил поведение агента: добавь сценарий в `internal/agent/agent_test.go` с фейковой моделью. Изменил системный промпт: прогони фразы из таблицы в README против настоящей модели.

## Стиль

- Комментарии и тексты для пользователя на русском, идентификаторы и логи на английском.
- Миграции только добавляются новыми файлами `NNNN_name.sql`, старые не редактируются.
- В тестах используй `storage/memstore` вместо PostgreSQL.
